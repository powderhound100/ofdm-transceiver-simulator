# ATSC 3.0 LDPC Decoder

Open-source LDPC decoder for receiving free over-the-air ATSC 3.0 (NextGen TV)
digital television using a software-defined radio.

Target: Seattle RF Channel 24 (KOMO/ABC + KIRO/CBS), unencrypted ATSC 3.0 OFDM
broadcasts.

## Architecture

```
SDR (RSP1B) → GNU Radio OFDM Demod → QAM Demapper → [LDPC Decoder] → BCH → ALP → HEVC → Display
                                                      ^^^^^^^^^^^^^^
                                                      THIS PROJECT
```

The LDPC decoder is the missing piece in a fully open ATSC 3.0 receive chain.

## Three Phases

| Phase | Implementation | Purpose | Status |
|-------|---------------|---------|--------|
| 1 | Python | Reference prototype, test vector generation | ✅ Complete (20/20 tests pass) |
| 2 | Rust + SIMD | Real-time software decode (~20 Mbps) | ✅ Complete (11/11 tests, bit-exact vs Python) |
| 3 | FPGA (Arty A7-100T) | Full-rate decode (~25+ Mbps) | 🔄 RTL complete, sim pending (needs iverilog) |

## Algorithm

Normalized Min-Sum (NMS) iterative decoding of QC-LDPC codes per ATSC 3.0 A/322:
- Code lengths: 16,200 (short) and 64,800 (normal) bits
- Lifting factor Z=360
- Code rates: 2/15 through 13/15
- Normalization factor alpha=0.75, max 50 iterations

## Project Structure

```
python/          Python reference decoder + test vector generator
rust/            Rust port with AVX2/NEON SIMD acceleration
fpga/            SystemVerilog RTL targeting Arty A7-100T (Artix-7)
test_vectors/    Shared test vectors (generated by Python)
docs/            Design documents and implementation plan
```

See [docs/PLAN.md](docs/PLAN.md) for the full implementation plan with
technical trade-offs, worktree structure, and verification matrix.

## Quick Start

```bash
# Python prototype
cd python
pip install -r requirements.txt
python test_ber.py          # Run BER simulation
python gen_test_vectors.py  # Generate test vectors for Rust/FPGA

# Rust decoder
cd rust
cargo test                  # Run tests against Python vectors
cargo bench                 # Benchmark throughput

# FPGA simulation
cd fpga/sim
make all                    # Run all testbenches (requires iverilog)
```
