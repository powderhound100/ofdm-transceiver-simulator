# OFDM Transceiver Simulator

Complete OFDM transceiver simulator with configurable channel models, multiple
channel estimation/equalization methods, LDPC coding, and comprehensive BER analysis.
Features an interactive dashboard and hardware implementations (Rust + SIMD, FPGA)
for real-time decoding applications.

## Architecture

```
SDR (RSP1B) → GNU Radio OFDM Demod → QAM Demapper → [LDPC Decoder] → BCH → ALP → HEVC → Display
                                                      ^^^^^^^^^^^^^^
                                                      THIS PROJECT
```

This project combines OFDM simulation with LDPC decoding, supporting multiple modulations
(QPSK, 16-QAM, 64-QAM), real-world channel models, and advanced estimation algorithms.

## Algorithm

Normalized Min-Sum (NMS) iterative decoding of QC-LDPC codes per ATSC 3.0 A/322:
- Code lengths: 16,200 (short) and 64,800 (normal) bits
- Lifting factor Z=360
- Code rates: 2/15 through 13/15
- Normalization factor alpha=0.75, max 50 iterations

Development code: IEEE 802.11n rate-1/2 N=648 Z=27 (smaller, faster to iterate).

## OFDM System Overview

### Multi-FFT Support

| Parameter | FFT=64 | FFT=256 | FFT=8192 |
|-----------|--------|---------|----------|
| CP Length | 16 | 64 | 2048 |
| Used Subcarriers | 52 | 208 | 6817 |
| Pilot Carriers | 13 (spacing=4) | 52 (spacing=4) | 1704 (spacing=4) |
| Data Carriers | 39 | 156 | 5113 |
| Max Channel Taps | 16 | 64 | 2048 |

Larger FFT = more pilots = better channel estimation = lower BER. This is the
fundamental reason ATSC 3.0 uses 8K/16K/32K FFT.

### Channel Estimation Methods

| Method | Description | Multipath Performance |
|--------|-------------|----------------------|
| **LS (legacy)** | Magnitude/phase interpolation, 4 pilots | Fails on multipath |
| **LS-Improved** | Re/Im linear interpolation, 13+ pilots | Works on simple channels |
| **LMMSE (DFT-based)** | Tikhonov-regularized DFT estimation | Best on all channels |

LMMSE algorithm (Edfors et al., IEEE Trans. Comm., 1998):
```
1. LS at pilots:       H_ls = Y_p / X_p
2. Partial DFT:        F_p[i,l] = exp(-j*2pi*pilot[i]*l/N)
3. Regularized LS:     h = (F_p^H*F_p + lambda*I)^-1 * F_p^H * H_ls
4. Full reconstruction: H = F_full * h
```

### Equalization Methods

| Method | Formula | Behavior |
|--------|---------|----------|
| **Zero-Forcing** | X = Y / H | Amplifies noise at frequency nulls |
| **MMSE** | X = H\*Y / (\|H\|^2 + sigma^2) | Bounded noise, always stable |

### Channel Models

| Model | Taps | Max Delay | Description |
|-------|------|-----------|-------------|
| `flat` | 1 | 0 us | Single tap, AWGN reference |
| `two_tap` | 2 | 0.83 us | Main + reflection at -3 dB |
| `tu6` | 6 | 5.0 us | COST207 Typical Urban 6-tap |
| `cost207_ra` | 6 | 0.5 us | COST207 Rural Area |
| `cost207_ht` | 6 | 5.0 us | COST207 Hilly Terrain |
| `brazil_a` | 3 | 2.22 us | Brazil indoor reception |
| `brazil_b` | 5 | 9.5 us | Brazil outdoor pedestrian |
| `brazil_c` | 6 | 2.8 us | Brazil vehicular urban |
| `brazil_d` | 6 | 20.0 us | Brazil mountainous / SFN |
| `brazil_e` | 6 | 23.0 us | Brazil SFN equal-power echoes |

Fading modes: **None** (deterministic), **Rayleigh** (CN(0,1) per tap), **Rician** (LOS + scatter).

## BER Test Results

### How BER Data is Generated

The simulation chain (`python/generate_ber_data.py`) sweeps SNR from -40 to +15 dB:

```
For each (SNR, channel, estimator, equalizer, FFT size, fading):
  For each seed in [42, 43, 44]:   # 3 independent trials
    1. Generate 324 random info bits
    2. LDPC encode → 648 coded bits (rate-1/2, 802.11n)
    3. QAM modulate → complex symbols (QPSK/16QAM/64QAM)
    4. OFDM: IFFT + cyclic prefix insertion
    5. Channel: multipath convolution + AWGN
    6. OFDM demod: CP removal + FFT + estimation + equalization
    7. Soft QAM demap → LLR (per-subcarrier noise variance)
    8. LDPC decode: NMS, alpha=0.75, max 50 iterations
    9. BER = (decoded bits != original info bits) / num_info_bits
  Average BER across seeds → one data point
```

Output: `ber_sweep_data.json` — consumed by dashboard and report.

**Key observations:**
- All channels converge to ~0.50 BER below -10 dB (noise dominates, random guessing)
- Flat/Two-tap waterfall at ~4-6 dB, COST207-HT at ~6-8 dB
- TU-6 has a BER floor at FFT=64 because its delay spread (30 samples at 6 MHz) exceeds
  the cyclic prefix (16 samples), causing ISI that no estimator can fix
- Legacy LS+ZF system remains broken at all SNR levels (BER never drops below 0.32)

### Fading Comparison (TU-6, LMMSE+MMSE, FFT=64)

| Fading | -20 dB | -10 dB | 0 dB | 5 dB | 10 dB | 15 dB |
|--------|--------|--------|------|------|-------|-------|
| None (deterministic) | 0.512 | 0.474 | 0.279 | 0.155 | 0.033 | 0.079 |
| Rayleigh | 0.519 | 0.479 | 0.277 | 0.125 | 0.000 | 0.005 |

Rayleigh fading produces random channel realizations per seed. Averaged over multiple
seeds, BER can be lower because some realizations have favorable frequency selectivity.
Both converge to ~0.50 at very low SNR (noise completely dominates).

## Interactive Dashboard

```bash
cd python && python run_dashboard.py
# Opens http://127.0.0.1:8050
```

Controls:
- **SNR** slider: -3 to 15 dB
- **Modulation**: QPSK / 16-QAM / 64-QAM
- **Channel**: All COST207 + Brazil profiles
- **Estimation**: LS / LS-Improved / LMMSE
- **Equalization**: Zero-Forcing / MMSE
- **FFT Size**: 64 / 256 / 8192
- **Fading**: None / Rayleigh / Rician (with K-factor slider)
- **Seed**: Random seed for reproducible experiments

6-panel display: Constellation (before/after EQ), PSD, Channel Response (true vs estimated), BER Waterfall, LDPC Convergence.
