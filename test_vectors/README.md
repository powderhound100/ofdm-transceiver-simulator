# Test Vectors

Generated by `python/gen_test_vectors.py`. These files are the contract between
all three implementations (Python, Rust, FPGA). If any implementation produces
different output for the same input, it has a bug.

## Generation

```bash
cd python
python gen_test_vectors.py    # generates all files below
```

All vectors use **fixed seed 42** for reproducibility. Same seed = same vectors = same results.

## SNR Test Points

| Label | SNR (dB) | Purpose |
|-------|----------|---------|
| high_noise | -2.0 | Decoder struggles, may not converge. Tests max_iter path |
| waterfall | -0.5 | Partial convergence. Tests typical operation |
| clean | +2.0 | Fast convergence. Tests early termination |
| noiseless | inf | Converges in 1 iteration. Basic sanity check |

## File Formats

### Code definition files

| File | Format | Description |
|------|--------|-------------|
| `base_matrix.json` | JSON | `{"mb": int, "nb": int, "z": int, "entries": [[int]]}` — base matrix with -1 for no-edge |
| `tanner_graph.json` | JSON | `{"cn_to_vn": [[int]], "vn_to_cn": [[int]]}` — adjacency lists |

### Per-SNR-point files

Naming: `<type>_snr_<label>.<ext>` (e.g., `llr_snr_waterfall_f32.bin`)

| File | Format | Description |
|------|--------|-------------|
| `llr_snr_<label>_f32.bin` | Binary, N little-endian float32 | Channel LLR values (for Rust) |
| `llr_snr_<label>_6bit.hex` | Text, N lines of 2-char hex | 6-bit 2's complement quantized LLR (for FPGA `$readmemh`) |
| `decoded_snr_<label>.bin` | Binary, N uint8 (0 or 1) | Expected decoded codeword bits |
| `info_bits_snr_<label>.bin` | Binary, K uint8 (0 or 1) | Original info bits (for BER computation) |
| `num_iters_snr_<label>.txt` | Text, single integer | Iterations to convergence (or max_iter) |

### Per-iteration intermediate data

Directory: `iter_messages_snr_<label>/`

| File | Format | Description |
|------|--------|-------------|
| `c2v_iter<NN>.hex` | Text, M lines | Check-to-variable messages after CNU. Each line: space-separated 2-char hex per edge |
| `v2c_iter<NN>.hex` | Text, N lines | Variable-to-check messages after VNU. Each line: space-separated 2-char hex per edge |
| `posterior_iter<NN>.hex` | Text, N lines of 2-char hex | Posterior LLR (6-bit quantized) |
| `syndrome_iter<NN>.txt` | Text, "PASS" or "FAIL" | Whether all parity checks passed |

## 6-bit Quantization

- Signed 2's complement: range [-32, +31] but we clip to [-31, +31]
- Hex encoding: `00` = 0, `1F` = +31, `21` = -31, `20` = -32 (unused/clipped)
- Quantization: `round(clip(float_val, -31, +31))`
- This matches the FPGA's 6-bit datapath exactly

## Consumers

| Consumer | Reads | Validates against |
|----------|-------|------------------|
| Rust unit tests | `*_f32.bin`, `tanner_graph.json` | `decoded_*.bin` (bit-exact) |
| Rust BER CLI | `*_f32.bin` | Python BER curve (within 0.1 dB) |
| FPGA `tb_ldpc_top` | `*_6bit.hex` | `decoded_*.bin` (bit-exact) |
| FPGA `tb_check_node_unit` | `c2v_iter*.hex`, `v2c_iter*.hex` | Python CNU output (bit-exact 6-bit) |
| FPGA `tb_variable_node_unit` | `posterior_iter*.hex`, `v2c_iter*.hex` | Python VNU output (bit-exact 6-bit) |
| FPGA `tb_barrel_shifter` | `base_matrix.json` (shift values) | Python `numpy.roll` reference |
